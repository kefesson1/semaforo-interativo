# 🚦 Semáforo Interativo com Alerta Sonoro para Pedestres

## 🎯 Objetivo Pedagógico
Projeto prático voltado para alunos da rede municipal (Ensino Fundamental), introduzindo conceitos de lógica sequencial, componentes de saída (visuais e sonoros) e tomada de decisão computacional através de entradas físicas.

## 🧠 Habilidades Desenvolvidas
- **Lógica de Programação:** Estruturas condicionais (`if/else`) e laços de repetição (`for`).
- **Eletrônica Básica:** Fluxo de energia, circuitos fechados, polaridade (ânodo/cátodo) e aterramento (GND).
- **Cidadania:** Associação da lógica do código com regras reais de trânsito e acessibilidade (sinal sonoro).

## 🛠️ Materiais Necessários
- 1x Placa Arduino UNO
- 1x Protoboard
- 3x LEDs (Verde, Amarelo, Vermelho)
- 3x Resistores (220Ω ou 330Ω)
- 1x Botão de Pressão (Pushbutton)
- 1x Buzzer (Piezoelétrico)
- Cabos Jumper

## 👨‍🏫 Dinâmica de Aula Sugerida (Dica para o Professor)
1. **Problematização (10 min):** Perguntar aos alunos como um semáforo de pedestres "sabe" que alguém quer atravessar.
2. **Mão na Massa (25 min):** Montagem guiada do circuito focando no uso correto do barramento negativo (GND) da protoboard.
3. **Lógica Visual (15 min):** Construção do código. Desafiar os alunos a alterarem o tempo de travessia modificando os valores da função `delay()`.
